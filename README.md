**Name:** Jann Arpon  
**Course:** BS Information Technology  

## Description
This is my submission for Activity 4. It is a multi-page mobile profile app built with Apache Cordova using standard HTML and CSS.

## App Pages
* **index.html** - Home page with my profile picture and a brief overview[cite: 1].
* **about.html** - Details about my background, education, and goals[cite: 3].
* **skills.html** - List of my tech skills and tools[cite: 5].
* **projects.html** - A list of sample projects I have built[cite: 4].
* **contact.html** - My contact details and a message form[cite: 2].

## Design Notes
* Styled using a single stylesheet (`css/style.css`) to make the page fit nicely on both phones and computers[cite: 6].
* Switching pages is done using standard HTML links (`<a>` tags).

## How to Run
1. Open PowerShell in the project folder.
2. Type `cordova platform add browser` if you haven't added it yet.
3. Type `cordova run browser` to test the app in your browser.
